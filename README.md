## About

An interactive RPG-style portfolio for Abdulrahman Alfeqy, a third-year Artificial Intelligence student at Menofia University. It presents selected work across agentic AI, LLM and RAG integrations, machine learning, data engineering, business intelligence, and full-stack Django development.

The site is built with **HTML, CSS, and vanilla JavaScript**. It has no framework, package manager, or build step; the RPG interface is an interactive way to explore profile, skills, experience, projects, education, achievements, freelance profiles, and contact information.

## Portfolio Features

- Eight RPG-inspired sections for profile, skills, experience, projects, freelance profiles, education, achievements, and contact.
- First-screen resume download and direct email action, alongside the game entry button.
- Skills grouped by applied area instead of self-assigned percentage scores.
- Live GitHub repository and follower data, with curated portfolio descriptions when a repository has no GitHub About description and a placeholder state if the API is unavailable.
- Email-first contact links for personal and university email.
- Animated starfield, XP progression, HUD, generated sound effects, and optional ambient audio controls.
- Keyboard-operable zone navigation, project links, and dialog controls with visible focus states.
- Responsive layouts for desktop and mobile.

## Run Locally

Clone the repository and serve the folder with any static HTTP server. For example:

```bash
git clone https://github.com/Abdulrahman-Alfeqy/Abdulrahman-Alfeqy.github.io.git
cd Abdulrahman-Alfeqy.github.io
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000). The main profile content is maintained in `portfolio-config.js`; page behavior is in `main.js`, layout and styles are in `index.html` and `styles.css`.
